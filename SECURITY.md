# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 8.1.x   | :white_check_mark: |
| < 8.1   | :x:                |

## Reporting a Vulnerability

If you suspect you have found a security vulnerability, [open a report](https://github.com/alexdlaird/pyngrok/security/advisories/new).
Please include a clear and concise description of what the vulnerability is, where it is exposed in the code, and (if
known) what best practices might apply to patching it.

If the issue is confirmed, a patch will be released as soon as possible.
